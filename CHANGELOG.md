# Changelog

All notable changes to this project are documented here. The format follows Keep a Changelog and the project uses Semantic Versioning.

## [0.1.0] - 2026-11-25

### Added
- Invoice ledger with outstanding, credit balance, aging buckets and status.
- DSO, best possible DSO, average days delinquent and CEI.
- Customer behavior and a 0-100 risk score with tiers.
- 13-week cash forecast with base, pessimistic and optimistic scenarios.
- Prioritized collections worklist and dunning drafts (never sent).
- Markdown, HTML, JSON, CSV and XLSX reports.
- Commands: analyze, forecast, dunning, validate, sample.
